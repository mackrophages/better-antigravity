# Think Hard

Start any prompt with `+` and that single turn engages maximum deep-reasoning rigor (`+MAX` on the status line), leaving every other prompt at your session's normal pace.

```text
> +plan the refactor of the parser and check concurrency edge cases
```

- `+task` activates Think Hard; `++` or a lone `+` is ignored.
- Also available explicitly as `/think-hard <task>`.

## Install

```bash
agy plugin install ./plugins/think-hard
```

4b. Porqués por causa

Causa A (Máquina): los plugins usaban mods TSX de 'claude-code' que Antigravity no carga. → faltaban plugin.json raíz, skills/*/SKILL.md y hooks.json de comandos. → fueron diseñados para el motor interno de Claude Code.
Por lo tanto: fueron diseñados como mods TSX de 'claude-code' → carecían de plugin.json, skills/ y hooks.json estándar → 0 de 11 cargaban en Antigravity.
Causa B (Medio): asumir jq, sips, magick o claude-haiku-5-5 rompía la ejecución en proot ARM64 y en agy. → jq y magick faltan y claude-haiku-5-5 no existe en agy models. → el código original asumía utilidades de escritorio y modelos de Anthropic.
Por lo tanto: asumir binarios ausentes y modelos ajenos → fallaba en proot ARM64 y en agy → vistas previas y medidores quedaban inactivos.
Causa C (Método): la web generaba comandos claude plugin incompatibles con agy. → agy instala por ruta o URL de GitHub con agy plugin install. → web/index.html solo tenía la plantilla de Claude Code.
Por lo tanto: web/index.html solo emitía claude plugin → agy rechazaba el comando → la instalación guiada fallaba.
